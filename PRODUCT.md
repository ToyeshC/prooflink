# Product

## Register

brand

## Users
Three audiences: (1) developers getting skills attested — scanning their GitHub, sharing a skill passport; (2) AI hiring agents querying skills via MCP tools or x402 micropayment API; (3) hackathon judges evaluating the product in a 60-second scroll. Primary design surface serves all three, but the 60s judge impression is the immediate goal.

## Product Purpose
Prooflink converts developer artifacts (GitHub profiles, Canvas LMS exports) into verifiable on-chain skill attestations anchored on Solana via the Solana Attestation Service. Acts as a decentralized talent oracle — queryable by AI hiring agents. Success = a developer can prove skills to an AI agent without human intermediary; a judge can understand that in one scroll.

## Brand Personality
Authoritative, Technical, Minimal. Voice: terse, infrastructure-confident, no hype. Tone: institutional credentialing meets developer tooling. Earns trust through precision and restraint, not loudness.

## Anti-references
- Generic crypto: neon-on-black, laser grids, coin-ticker aesthetics, meme vibes
- SaaS cream: purple gradients, Stripe-clone hero metrics, Tailwind defaults, floating orbs
- Hacker terminal: green-on-black, ASCII art overload, monospace as decoration not function

## Design Principles
1. **Proof over claims** — show verifiable evidence, not marketing copy; the UI itself should feel like a credential
2. **Machine-native confidence** — design for AI agents and technical users; precision signals trust better than warmth
3. **Signal over decoration** — every element earns its place; no decoration that doesn't carry information
4. **Institutional weight** — feel like a credentialing authority, not a startup landing page
5. **60-second legibility** — a hackathon judge should understand the full value proposition in one scroll

## Accessibility & Inclusion
WCAG AA. Color contrast minimum 4.5:1 for normal text, 3:1 for large text. Keyboard navigation for primary flows. Screen reader basics (alt text, ARIA labels on interactive elements). Reduced motion consideration.
